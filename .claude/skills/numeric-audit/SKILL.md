# 数值溯源审计（Numeric Audit）

对目标文档（论文/报告/README）执行**逐数字**三分类检查：

## 方法
1. 提取文档中全部数值主张（表格、正文、图注、摘要）；
2. 对每个数字判定：
   - **verified**：在 `data/*.json|csv` 有出处（给出文件+字段）；
   - **derived**：源数据简单换算（给出换算式并实际复算）；
   - **unsourced / hallucination-suspected**：两者皆不满足。
3. 抽样复算 ≥5 处（用项目 Python 环境真跑，不心算）；
4. 按严重度输出：`hallucination-suspected > must-fix > should-fix > info`。

## 已知陷阱（实战教训）
- **换算单位错配**：mΩ↔W（P=I²R）除错量纲曾把 5.30 W/m 当 13.26 W/m；
- **单调和量纲快检**：引用别人的数前先过一遍单调性（单调下降序列的 Richardson 外推必小于末项——此判据曾抓出 4.654 不可能）；
- **同值不同口径**：一个量存在多口径时（如单站并联 vs 串联、refine 级别、面积修正），正文两处必须显式标注口径；
- **表格配对顺序**：并列值（N=37/61，β=2.19/2.81）逐对检查是否写反；
- **摘要/README 等高可见度位置最常携带旧口径**——终稿更新后必查；
- 计数类声明（"24 条记录"）要 grep 实数。

## 输出格式
```
[severity] 文档:行 | 主张 | 判定（出处/换算式/无源）| 修正值
```
