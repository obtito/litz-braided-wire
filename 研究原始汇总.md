# Open-source EM solvers for eddy-current simulation on macOS

## 1. [HIGH|V|tool] NGSolve (pip-installable FEM with Python API, native macOS wheels)
URL: https://pypi.org/project/ngsolve/
DESC: Finite element framework with full Python front-end (NGS-Py). PyPI JSON verified: v6.2.2607 ships macosx_10_15_universal2 wheels for CPython 3.10-3.14, so `pip install ngsolve` runs natively on both Apple Silicon and Intel Macs. Supports complex-valued time-harmonic problems on H(curl)-conforming edge-element (Nedelec/HCurl) spaces - the standard discretization for magnetoquasistatic A-v eddy-current problems. Interactive i-tutorials at ngsolve.org/docu/latest/i-tutorials/index.html (page fetched, covers Maxwell/edge-element units); Netgen mesher is bundled.
NOTES: Recommended primary solver for the hackathon. Workflow: mesh cross-section (2D, Q1/Q2) or a braid period (3D, Q3), build complex system a la (nu*curl A, curl v) + i*omega*sigma*(A, v), impose net current I=20 A via per-conductor constraint, integrate sigma*|E|^2 over copper for W/m, Rac = P/I_rms^2. Same model re-solved over the 50 kHz-1 MHz sweep in seconds, so scipy.optimize loops for Q3 are cheap.

## 2. [HIGH|V|tool] GetDP + Gmsh (ONELAB) - manual contains a complete 2D a-v eddy-current worked example
URL: https://getdp.info/
DESC: GPL FEM solver specialized in electromagnetics (Dular/Geuzaine, U Liege). Homepage verified; precompiled versions exist for Windows, Linux AND macOS. Its reference manual (getdp.info/doc/texinfo/getdp.html, fetched in full) documents 2D plane AND axisymmetric magnetodynamics via the a-v formulation and ships a COMPLETE worked example MagDyn_av_2D.pro / CoreMassive.pro: conducting region with sigma = 5.9e7 S/m, harmonic Frequency analysis, Current_2D global constraint imposing the total current through the conductor, and ready PostProcessing of j, jz, roj2 = |J|^2/sigma (ohmic power density) and U/I (impedance). Weak form (verified quote): Galerkin [ nu[] Dof{d a}, {d a}] + [ sigma[] Dof{a},{a} ] with i*omega terms in frequency domain.
NOTES: Fastest route to a validated Q1: adapt MagDyn_av_2D.pro (set Freq=200kHz, sigma=5.8e7, Current_2D = 20 A). Losses per unit length come directly from the roj2 surface integral; impedance from U/I. Script parametric sweeps by regenerating .pro files from a Python template; mesh with gmsh - `brew install gmsh` verified in Homebrew API (formula 4.15.2, homepage gmsh.info), or pip install gmsh.

## 3. [HIGH|V|tool] FEMM 4.2 + pyfemm (industry-standard 2D magnetics, Windows-only binary)
URL: https://www.femm.info/wiki/Download
DESC: Finite Element Method Magnetics (D. Meeker, Aladdin Free Public License): free 2D planar + axisymmetric solver with built-in time-harmonic eddy currents - the de-facto standard for winding-loss cross-section studies (current industry litz-sizing practice is a 2D FEMM model of the winding window, per litz.pro workflow descriptions). Download page verified: 'A Windows finite element solver' - no native macOS build. pyfemm (pypi.org/project/pyfemm/, fetched) is the Python scripting interface; its only OS classifier is Windows.
NOTES: On macOS run under Wine/CrossOver, a VM, or the community Flatpak thalesmaoa/femm-unofficial inside a Linux container. Planar problems define a 'depth' - set 1 m to get Rac per meter directly; manual at femm.info/Archives/doc/manual42.pdf covers skin-effect eddy analysis. groups.io/g/femm discusses litz modeling: homogenized bundle continuum vs drawing hundreds of strands. Example pyFEMM eddy automation: github.com/MIPIthon/pyFEMM_Eddy_Current_Spice_Model (active 2026).

## 4. [HIGH|V|tool] scikit-fem (pure-Python FEM assembly, pip, runs anywhere)
URL: https://github.com/kinnala/scikit-fem
DESC: Pure Python 3.10+ assembly library, zero compiled code, minimal deps (numpy+scipy); README verified: `pip install scikit-fem[all]`, includes Nedelec and Raviart-Thomas edge elements plus native complex-valued bilinear forms - everything needed to hand-write the 2D cross-section A-v eddy-current weak form. PyPI: v12.0.2, 'Operating System :: OS Independent' (verified). JOSS paper doi:10.21105/joss.02369. Example gallery (scikit-fem.readthedocs.io listofexamples, checked) has no dedicated eddy-current example - you build it from the Poisson/Helmholtz templates.
NOTES: Best choice for full control on a Mac: build strand-pack cross-sections as MeshTri (via shapely or gmsh meshes through meshio), assemble complex A matrix, factorize once with scipy.sparse.linalg.splu and reuse across the frequency sweep and across Q3 geometry iterations. No license friction (BSD-style per project).

## 5. [HIGH|V|github-repo] ethz-pes/litz_wire_losses_fem_matlab (Bessel-function litz loss extraction from field patterns)
URL: https://github.com/ethz-pes/litz_wire_losses_fem_matlab
DESC: ETH Zurich PES (T. Guillod), BSD-2-Clause, README fetched: MATLAB tool (R2018b+, no toolboxes) computing litz-wire losses from externally computed field patterns using frequency-domain Bessel functions. Needs only volume integrals of |J|^2 and |H|^2 over a homogenized winding block. Key properties: mesh can be coarse and INDEPENDENT of skin depth; valid up to several MHz; handles arbitrary bundle shape via fill factor. Stated limitations: neglects the eddy currents' reaction field, round strands, ideal twisted litz, no explicit strand positions. Companion repos from API search: ethz-pes/litz_wire_homogenization_comsol_matlab (26 stars, active 2026-03) and otvam/litz_wire_losses_twisting (twisting imperfections, 2025-11).
NOTES: Pair with any solver above for Q2/Q3: run one coarse homogenized 2D field solve (skin + proximity field patterns), then evaluate per-frequency strand losses analytically for the whole 50 kHz-1 MHz sweep - avoids meshing 100+ strands to sub-skin-depth resolution. Field patterns can come from any software (their example used COMSOL; GetDP/NGSolve output works the same).

## 6. [MEDIUM|V|tool] ElmerFEM (WhitneyAVSolver / MagnetoDynamics - capable but hard to install on macOS)
URL: https://github.com/ElmerCSC/elmerfem
DESC: Open-source GPL multiphysics FEM. GitHub releases page fetched: v9.0/9.1 release notes detail MagnetoDynamics updates including the WhitneyAVSolver (edge-element A-v) with a time-harmonic AV model, surface-impedance boundary conditions, and a MagnetoDynamics2D (2D) module with core losses - i.e. genuine 200 kHz eddy-current capability (classic induction-heating usage). However, releases contain a Windows installer plus source; no official macOS dmg.
NOTES: macOS: compile from source - GitHub issue #503 'Compile elmerFEM natively for apple silicon?' (Jul 2024) documents M1 builds with Homebrew CMake - or run the Elmer Docker image. Community tutorial 'Simulating Electromagnetics with ElmerFEM' (wiki.f-si.org, Jun 2024); fem/tests/ has mgdyn_* eddy test cases. Rank behind NGSolve/GetDP/scikit-fem for a Mac-only team under time pressure.

## 7. [MEDIUM|UNVERIFIED|paper] Improved Winding Losses Calculation Based on Bessel Functions (TU Delft)
URL: https://research.tudelft.nl/files/153829474/Improved_Winding_Losses_Calculation_Based_on_Bessel_Functions.pdf
DESC: Paper on Bessel-function-based winding-loss calculation; explains where Dowell/Ferreira 1-D approximations deviate from FEM. Found via search; not fetched. Provides the analytical baseline needed for the Q1 'validate against theory' requirement.
NOTES: Exact MQS solution for an isolated round wire: J(r) proportional to J0(k r), k=(1+j)/delta, delta=sqrt(2/(omega*mu*sigma)) = 0.147-0.148 mm at 200 kHz for sigma=5.8e7; Rac/Rdc = Re[ k*a*J0(k*a) / (2*J1(k*a)) ], a=1 mm gives k*a ~ 6.8(1+j). scipy.special.jv handles complex arguments. Pair with Sullivan's 'Simplified Design Method for Litz Wire' (ryz.ece.illinois.edu/pdf/simplitz_apec2014.pdf) for strand-diameter heuristics.

## 8. [LOW|UNVERIFIED|tool] PyAEDT (Python API for Ansys Electronics Desktop - license-gated fallback)
URL: https://github.com/ansys/pyaedt
DESC: MIT-licensed Python wrapper (pip install pyaedt) automating Ansys Electronics Desktop, including Maxwell 2D/3D Eddy Current and Transient solvers, HFSS, Q3D. The wrapper is open source but AEDT itself is commercial closed-source software requiring a valid Ansys license. Found via web search; repository page not fetched.
NOTES: Fallback only if an ANSYS license materializes during the hackathon; the open-source stack above (NGSolve or GetDP for solving, gmsh for meshing, ETH MATLAB tool for litz post-processing) fully covers Q1-Q3 on macOS without it.

## KEY INSIGHTS
- Model the 1 m wire as a 2D cross-section phasor problem (magnetoquasistatic A-v formulation), not a 3D model: solve for complex A_z with one scalar potential unknown per conductor enforcing the net current I=20 A; then J_z = sigma*(-j*omega*A_z - dV/dz) and Rac per meter = (1/I_rms^2) * integral of |J_z|^2/sigma over the copper area. GetDP's manual documents exactly this with a complete worked example (MagDyn_av_2D.pro: Current_2D constraint, harmonic Frequency analysis, roj2 = |J|^2/sigma loss post-processing, U/I impedance). Source: https://getdp.info/doc/texinfo/getdp.html
- Best native-macOS toolchain is NGSolve via pip - PyPI v6.2.2607 verified to ship macosx universal2 wheels for CPython 3.10-3.14 - or pure-Python scikit-fem (pip install scikit-fem[all], Nedelec elements, 'OS Independent'). Both give fully scriptable complex-valued eddy-current solves so the 50 kHz-1 MHz sweep and Q3 optimization loops run in-process under scipy. Sources: https://pypi.org/project/ngsolve/ , https://github.com/kinnala/scikit-fem
- FEMM, the free industry-standard tool for winding-window litz-loss studies, is Windows-only (verified on femm.info download page; the pyfemm pip package likewise carries only Windows classifiers) - on macOS it needs Wine/CrossOver, a VM, or the thalesmaoa/femm-unofficial Flatpak in a container. Its planar 'depth' parameter set to 1 m yields Rac per meter directly, which is why it is the classic benchmark workflow. Sources: https://www.femm.info/wiki/Download , https://pypi.org/project/pyfemm/
- Analytic validation for Q1: skin depth delta = sqrt(2/(omega*mu*sigma)) = 0.147-0.148 mm at 200 kHz in copper (sigma=5.8e7 S/m); the isolated round wire has J(r) proportional to J0(k*r) with k=(1+j)/delta and Rac/Rdc = Re[ k*a*J0(k*a) / (2*J1(k*a)) ] (Kelvin/Bessel solution; tends to 1 as k*a -> 0, so it sanity-checks both limits). Mesh guidance: a/delta ~ 6.8 for the 2 mm wire, so use graded meshing with 2-3 elements per skin depth near the surface. Source: https://research.tudelft.nl/files/153829474/Improved_Winding_Losses_Calculation_Based_on_Bessel_Functions.pdf
- Do not resolve every strand to sub-skin-depth resolution: ETH Zurich's BSD-licensed MATLAB tool extracts litz skin+proximity losses from coarse-mesh homogenized field patterns using frequency-domain Bessel functions (mesh independent of skin depth, valid to several MHz), making the full frequency sweep and Q3 scheme comparisons cheap; its stated limitation (neglects eddy-reaction field) also defines when you must fall back to strand-level 2D FEM. Source: https://github.com/ethz-pes/litz_wire_losses_fem_matlab
- ElmerFEM has real eddy-current capability (WhitneyAVSolver time-harmonic A-v plus surface-impedance BC per its verified release notes) but no official macOS build - Apple Silicon requires compiling from source (GitHub issue #503) or Docker - so for a Mac team it ranks behind NGSolve/GetDP/scikit-fem; PyAEDT automates Maxwell Eddy Current nicely but inherits the commercial ANSYS license dependency. Sources: https://github.com/ElmerCSC/elmerfem , https://github.com/ansys/pyaedt

# GitHub code for Litz-wire / winding AC-loss modeling

## 1. [HIGH|V|github-repo] otvam/litz_wire_losses_twisting — Litz Wire Losses with Custom Twisting
URL: https://github.com/otvam/litz_wire_losses_twisting
DESC: MATLAB tool by Thomas Guillod (ETH Zurich / now Dartmouth College) computing losses of a litz wire winding with arbitrary twisting via a 2.5D method: strand coordinates -> permutation matrix representing the twist -> DC R/L impedance matrices -> permutation applied to impedance matrix -> current-sharing solve among parallel strands -> internal+external field per strand -> Bessel-function analytical strand losses. Companion scripts run_straight.m (untwisted), run_twisted.m (fully twisted), run_random.m (random twisting). Simplified open version of Guillod/Huber/Krismer/Kolar, 'Litz Wire Losses: Effects of Twisting Imperfections', IEEE COMPEL 2017 (DOI 10.1109/COMPEL.2017.8013327; paper.pdf included). Directly models exactly what Q3/Q4 need: transposition schemes as permutation matrices and the resulting Rac penalty and current-sharing imbalance.
NOTES: MATLAB R2018b/2019a/2024b, NO toolboxes required, GNU Octave probably works with minor edits — runs natively on macOS. BSD-2-Clause. Badge says 'unmaintained' but code is complete and self-contained. Approximations: DC (not AC) R/L matrices; field inside strands assumed constant. Note: a GitHub search for 'K-TLitz'/'topological braiding' found no public code from the CTMA/K-TLitz project itself (only unrelated quantum-anyon braiding repos), so the braid-topology generator must be written from scratch — this repo supplies the loss/physics half.

## 2. [HIGH|V|github-repo] otvam/pypeec — PyPEEC 3D Quasi-Magnetostatic FFT/PEEC Solver (Dartmouth PMIC)
URL: https://github.com/otvam/pypeec
DESC: Pure-Python open-source 3D quasi-magnetostatic PEEC solver developed at Dartmouth College within the Power Management Integration Center (PMIC — Charles Sullivan's center; this IS the Dartmouth code release). FFT-accelerated and GPU-accelerated; frequency-domain (DC and AC) solution with skin effect; conductive and magnetic domains; imports STL/PNG/GERBER geometry or draws with voxel indices/stacked 2D vector shapes; extracts current density, flux density, losses, terminal R/L; targets inductors, transformers, chokes, IPT (wireless power) coils, busbars. JOSS paper: doi.org/10.21105/joss.06644. Strong open-source ANSYS/COMSOL substitute for Q1-Q3 simulation on macOS.
NOTES: Install: 'pip install pypeec' or 'conda install -c conda-forge pypeec' — runs natively on darwin. MPL-2.0 license. Docs at pypeec.otvam.ch; Jupyter-notebook and ParaView compatible; CLI or Python API. Limitations: no capacitive/dielectric effects, no advanced boundary conditions; geometry is voxel-based (strands must be resolvable as voxels — fine for 2 mm wire at delta=0.147 mm but expensive for many sub-0.2 mm strands, so pair with the analytical strand-loss post-processors below).

## 3. [HIGH|V|github-repo] ethz-pes/litz_wire_losses_fem_matlab — Litz Losses from External Field Patterns
URL: https://github.com/ethz-pes/litz_wire_losses_fem_matlab
DESC: MATLAB tool (ETH Zurich Power Electronic Systems Lab) computing litz-wire winding losses in the frequency domain using Bessel functions, taking as input only two field integrals from ANY simulation software (COMSOL, ANSYS, OpenFOAM — hence also FEMM/Elmer): integral of J^2 over the winding (skin losses) and integral of H^2 over the winding (proximity losses). Mesh can be coarse, independent of skin depth; valid up to several MHz; arbitrary wire shape. Key architectural idea for the hackathon: decouple a coarse open-source FEM field solve from strand-level analytical loss computation, giving a fast Q2/Q3 surrogate cross-checkable against full FEM.
NOTES: MATLAB, no toolboxes required; BSD-2-Clause; example uses COMSOL 5.4/5.5 but the interface is solver-agnostic. Assumes ideal (perfectly transposed, insulated) round litz defined by fill factor — exact strand positions not modeled. Status 'unmaintained' but code stable; example scripts run_winding_fem.m and run_winding_circuit.m.

## 4. [HIGH|V|github-repo] Sheldour/DAB3-Transformer-Litz-Wire-Analysis — Sullivan n_opt + Tourkhani-Viarouge Rac
URL: https://github.com/Sheldour/DAB3-Transformer-Litz-Wire-Analysis
DESC: Small MIT-licensed MATLAB repository implementing exactly the classical analytical models Q2 needs: (1) calculate_nopt_sullivan_paper_parameters.m — closed-form optimal number of litz strands n_opt and optimal strand diameter from window geometry and frequency, per C.R. Sullivan, 'Optimal choice for number of strands in a litz-wire transformer winding', IEEE Trans. Power Electronics, 1999; (2) calculate_Rac_Tourkhani_simple.m — analytical AC resistance of round litz windings per Tourkhani & Viarouge, IEEE Trans. Magnetics, 2001, comparing exact Kelvin-function evaluation vs Taylor-series approximations. User inputs (f_s, turns N, window b_b, h) at top of script.
NOTES: Plain .m scripts, trivially portable to Python/NumPy (scipy.special has kelvin functions for the exact branch) for the optimization inner loop on macOS. 0 stars but formulas are standard and referenced to the primary papers. MIT license; last pushed 2026-04.

## 5. [HIGH|V|github-repo] OpenMagnetics/MKF (+ PyOpenMagnetics) — Magnetics Knowledge Foundation
URL: https://github.com/OpenMagnetics/MKF
DESC: Actively maintained (pushed 2026-09) C++ simulation engine behind openmagnetics.com with Python bindings (PyOpenMagnetics/PyMKF). README documents the exact loss models per wire type: skin losses — Albach (round and litz; IEEE TPEL doi 10.1109/tpel.2011.2143729), Kutkut (rectangular/planar/foil); proximity losses — Lammeraner (round), Ferreira (litz; IEEE 9485268), Albach (rectangular); plus iGSE/Steinmetz core losses, air-gap reluctance (Zhang), fringing field (Roshen), leakage inductance. Free web UI at openmagnetics.com for cross-checking numbers without installing anything.
NOTES: C++ core with Python wrapper repos in the same org; BSD-style licensing per project. Ferreira's litz proximity model uses the erf/gamma-function formulation valid for strand d <~ 2*delta — exactly the regime of Q2 (d ~ 0.05-0.1 mm at 200 kHz). Use as independent second implementation to validate the team's own surrogate.

## 6. [MEDIUM|V|github-repo] ethz-pes/litz_wire_homogenization_comsol_matlab — Litz Homogenization (complex mu, sigma)
URL: https://github.com/ethz-pes/litz_wire_homogenization_comsol_matlab
DESC: COMSOL+MATLAB tool extracting homogenized material parameters for a litz wire — a virtual complex permeability and complex conductivity such that energy and losses of the homogeneous material match the stranded wire. Reports <2% deviation vs simulating all discrete strands, valid to several MHz, arbitrary wire shape, eddy-current reaction on the field included; run_1..4 example scripts compare homogenized vs discrete simulation of a circular air-core litz coil (energy, losses, induced voltage). This is the method to cite/implement when a 3D braid (Q4) must be simulated without meshing hundreds of strands.
NOTES: Requires COMSOL with MATLAB LiveLink — license risk for this team; treat as algorithm reference to re-implement (the complex-mu/sigma fitting idea ports to FEMM/Elmer/GetDP or PyPEEC). README warns COMSOL 6.3 now ships a built-in litz homogenized model making the package redundant in COMSOL. BSD-2-Clause, 26 stars.

## 7. [MEDIUM|V|github-repo] otvam/magnetic_components_toolbox_matlab — Power Magnetics Model & Optimization Toolbox
URL: https://github.com/otvam/magnetic_components_toolbox_matlab
DESC: Object-oriented MATLAB toolbox for modeling/optimizing MF inductors and transformers: solid-wire and stranded (litz) windings including skin AND proximity losses via the mirroring method with inductance-matrix field evaluation (with/without air gaps), winding-head model, iGSE core losses with locally fitted loss maps, mass/volume computation, equivalent-circuit extraction, and parallel brute-force optimization producing Pareto fronts. Two complete 5 kW worked examples (SRC-DCX resonant transformer, bidirectional Buck inductor) demonstrate the full optimize-then-plot workflow the hackathon Q3 asks for.
NOTES: MATLAB, BSD-2-Clause, 27 stars, 'unmaintained' badge but pushed 2025-06. Extendable via abstract classes for custom winding geometries. Same author (Guillod) as the twisting repo — the litz loss routines are consistent and can be reused together.

## 8. [MEDIUM|V|github-repo] OpenMagnetics/cci_coords — Strand Packing Coordinates for Litz Wires
URL: https://github.com/OpenMagnetics/cci_coords
DESC: Data repository with precomputed coordinates of strand centers for packing N equal circles into a circle (best-known circle-packing-in-circle solutions, based on the Otto-von-Guericke-Universitaet Magdeburg packing archive at hydra.nat.uni-magdeburg.de/packing/cci/cci.html). Gives exact, non-overlapping strand positions for a round litz bundle — ready-made input for the Q2 parametric geometry and for the per-station cross-section states of the Q4 braid animation.
NOTES: Pure coordinate data (no build); trivially consumed from Python on macOS to generate FEMM/PyPEEC/Gmsh geometry scripts and Three.js cross-section views. Pair with an enamel+interstrand margin factor when converting packing coordinates to physical strand radii.

## KEY INSIGHTS
- The single most transferable code asset for Q3/Q4 is otvam/litz_wire_losses_twisting (https://github.com/otvam/litz_wire_losses_twisting): it represents a twist/transposition as a permutation matrix applied to the strand impedance matrix, solves the current-sharing problem of parallel strands, and computes per-strand losses with Bessel functions — the exact mathematical machinery needed to score different braid schemes fast; validated methodology in Guillod et al., IEEE COMPEL 2017, DOI 10.1109/COMPEL.2017.8013327 (paper PDF bundled).
- The Dartmouth answer: Charles Sullivan's Power Management Integration Center released PyPEEC (https://github.com/otvam/pypeec) — a pure-Python, FFT/GPU-accelerated 3D quasi-magnetostatic PEEC solver (pip/conda-forge, MPL-2.0, JOSS doi 10.21105/joss.06644) with frequency-domain AC/skin-effect solves and STL import; it is the strongest ANSYS-free 3D solver option that runs natively on macOS, and co-author Thomas Guillod (now Dartmouth) also authored the litz twisting-loss code above.
- Ready-made analytical surrogates exist for the Q2/Q3 optimization loop: Sheldour/DAB3-Transformer-Litz-Wire-Analysis (https://github.com/Sheldour/DAB3-Transformer-Litz-Wire-Analysis) codes Sullivan's 1999 closed-form optimal strand count/diameter and the Tourkhani-Viarouge 2001 exact Kelvin-function Rac; OpenMagnetics/MKF (https://github.com/OpenMagnetics/MKF) codes Albach skin-loss and Ferreira litz proximity-loss models (Ferreira's formulation is the standard choice for strand d <~ 2*delta, i.e. d ~ 0.05-0.1 mm at 200 kHz where delta = 0.147 mm) — use the two as cross-implementations.
- Fastest Q2/Q3 architecture found in the literature code: solve the field ONCE with a coarse FEM whose mesh ignores the skin depth, then compute strand-level skin losses from integral(J^2) and proximity losses from integral(H^2) analytically with Bessel functions (ethz-pes/litz_wire_losses_fem_matlab, https://github.com/ethz-pes/litz_wire_losses_fem_matlab; solver-agnostic, so FEMM or Elmer output works); for full-bundle 3D sims, homogenize the litz into a complex permeability + complex conductivity with <2% error up to MHz (ethz-pes/litz_wire_homogenization_comsol_matlab, https://github.com/ethz-pes/litz_wire_homogenization_comsol_matlab).
- For bundle geometry, OpenMagnetics/cci_coords (https://github.com/OpenMagnetics/cci_coords) provides precomputed best-known circle-packing coordinates of N strands in a round bundle — direct input for parametric Q2 cross-sections, FEM/PEEC mesh generation, and the Q4 per-station cross-section animation.
- Negative result: GitHub API searches for 'K-TLitz', 'TLitz', and 'topological braiding' return no code from the CTMA/K-TLitz project backing this problem (only unrelated quantum-anyon braiding toys), and no public Sullivan-group litz-optimization repo exists beyond PyPEEC and Guillod's repos — the braid-word/event-graph compilation layer of Q4 has no off-the-shelf implementation and must be authored by the team.

## 1. [HIGH|V|github-repo] TexGen (louisepb/TexGen mirror)
URL: https://github.com/louisepb/TexGen

# Literature: Litz wire design theory and loss models

## 1. [HIGH|V|paper] Sullivan & Zhang, "Simplified Design Method for Litz Wire" (IEEE APEC 2014, pp. 2667-2674)
URL: https://ryz.ece.illinois.edu/pdf/simplitz_apec2014.pdf
DESC: The single most actionable litz design paper (311+ citations); full text read and formulas verified. Deliberately conservative strand-count method: skin depth delta = sqrt(rho/(pi*f*mu0)); recommended strand count n_e = k*delta^2/(b*N_s) with k from Table I (k=1.0 one-level twisted bundle / true braid, 1.33 for two- and three-level bundling, 2.0 untwisted); proximity-only resistance factor F_R = 1 + (pi*n*N_s)^2 * d_s^6 / (192*delta^4*b^2); max strands in the FIRST twisting operation n1,max = 4*delta^2/d_s^2; construction rule: 4-5 bundles at each subsequent twisting level; optimal strand diameter is a fraction of delta (good designs use d_s <= delta/2 to delta/4). Also gives eddy loss of a cylinder in uniform field P = pi*l*d^4/(64*rho)*(dB/dt)^2 and the solid-wire benchmark F_R,solid = 1/(2q)*Im[J0(q)/J1(q)], q = sqrt(2j)*R/delta (J0,J1 = modified Bessel). b = winding breadth, N_s = turns/layer (for a straight 1 m wire take b ~ bundle diameter, N_s = 1).
NOTES: Serves Q2 directly and Q3 framing. For this problem at 200 kHz: delta = 0.1476 mm; J_dc<=4 A/mm^2 at 20 A RMS needs A_cu >= 5 mm^2. Choose d_s = 0.04-0.07 mm (d/delta = 0.27-0.48; AWG48-AWG41): d=50um -> N~2546 strands, n1,max = 35 -> 3 twisting levels (35 x 35 x ~2); d=71um -> N~1265, n1,max = 17 -> 3 levels. Frequency sweep: delta = 0.295 mm @50 kHz, 0.066 mm @1 MHz. Mirror PDF also free at elektrisola.com (https://www.elektrisola.com/Attachments/LitzWire%20Info/SimplifiedDesignMethodforLitzWire.pdf).

## 2. [HIGH|V|paper] Umetani, Kawahara, Acero, Sarnago, Lucia, Hiraki, "Analytical Formulation of Copper Loss of Litz Wire With Multiple Levels of Twisting Using Measurable Parameters" (IEEE Trans. Industry Applications 57(6), 2021)
URL: https://www.cc.okayama-u.ac.jp/~eng_epc/pdf/IAS2021_Umetani.pdf
DESC: Full text read (free author copy). Fully analytical loss model for MULTI-LEVEL twisted litz with exact Kelvin-function strand factors: F(g_s) = g_s*(ber g_s * bei' g_s - bei g_s * ber' g_s)/(2*(ber' g_s^2 + bei' g_s^2)), K(g_s) = -2/(g_s*(ber^2+bei^2))*(ber g_s * bei' g_s - bei g_s * ber' g_s) - 1, with g_s = d_s*sqrt(f*pi*mu_0*sigma_s); internal inductances L_r, M_i also in closed form. Models each higher twisting level as a homogeneous effective medium with effective resistivity rho_e = rho/m, where m = (twisting length)/(mean circumference traversed) is the twisting length ratio of level-q strands; level structure defined by bundle counts m1,m2,m3 and mean radii. Derives the MINIMUM twisting length condition (eqs. 51/56/57) under which bundle-level proximity loss becomes negligible - a computable sufficiency criterion for transposition quality. Reference list (read) pins exact citations for the whole canon: Dowell 1966 (PIEE 113(8):1387-1394), Ferreira 1992 (IEE Proc.-B 139(1):21-25), Ferreira 1994 (IEEE TPEL 9(1):127-131), Lotfi & Lee 1993 (IAS vol.2 pp.1169-1175), Bartoli 1996, Sullivan 1999, Nan & Sullivan 2003/2009 COMPEL, Rosskopf 2014, Sullivan & Zhang COMPEL 2014 "Analytical model for effects of twisting on litz-wire losses".
NOTES: Serves Q2 (exact strand curves), Q3 (level-by-level loss budget), and Q4 (the minimum-length condition + radial/azimuthal coverage can be assembled into the 'perfect transposition' criterion). Implement F/K with scipy.special (ber/bei available as scipy.special.kelvin). The companion 2019 APEC paper "Simple Fully Analytical Copper Loss Model of Litz Wire Made of Strands Twisted in Multiple Levels" (semanticscholar.org/paper/6f6bcb4b61d9d7db2896c2d5740743d16ba22db0) is the shorter version.

## 3. [HIGH|V|github-repo] otvam/litz_wire_losses_twisting (Thomas Guillod, ETH Zurich / Dartmouth)
URL: https://github.com/otvam/litz_wire_losses_twisting
DESC: README read and verified. MATLAB tool (BSD-2-Clause, no toolboxes, tested R2018b/2019a/2024b) implementing the COMPEL 2017 paper "Litz Wire Losses: Effects of Twisting Imperfections" by Guillod, Huber, Krismer, Kolar (DOI 10.1109/COMPEL.2017.8013327; paper.pdf included in repo). 2.5D method: input strand coordinates -> twisting defined by a PERMUTATION MATRIX acting on the strand impedance matrix -> solves CURRENT SHARING among parallel-connected strands -> computes internal+external field at each strand -> strand losses analytically with Bessel functions. NOTES: Directly serves Q2 (current sharing between strands is an explicit deliverable of the problem) and Q3/Q4: the twisting permutation matrix IS a braid-word/transition-matrix abstraction - braid sequences from Q4 can be fed in as permutations, and it quantifies how twisting imperfection degrades Rac. ## 4. [HIGH|V|paper] Zhang, White, Kassakian (MIT), "Realistic Litz Wire Characterization using Fast Numerical Simulations" (IEEE APEC 2014)

## 5. [HIGH|V|paper] Sullivan, "Optimal Choice for Number of Strands in a Litz-Wire Transformer Winding" (IEEE Trans. Power Electronics 14(2):283-291, 1999)

# Theory of complete/perfect transposition: Roebel cables, CTC, transformer practice, braid math

## 1. [HIGH|V|paper] Goldacker et al. 2014, "Roebel cables from REBCO coated conductors: a one-century-old concept for the superconductivity of the the future" (arXiv:1406.4244)
URL: https://arxiv.org/abs/1406.4244
DESC: The foundational review (~400 citations) of Roebel cables: the core idea is to split current into strands and provide FULL transposition of strands along the cable length. Covers the original 1914 Roebel bar concept (invented precisely to reduce skin effect and eddy currents in copper), punched/laser-cut meandering strand geometry, transposition length selection, and measured AC-loss reductions (roughly a factor ~2 vs a monolithic equivalent because effective strand width is about half the cable width).
NOTES: Design rules to reuse in Q3/Q4: transposition pitch is typically 13-17 strand widths; a 5-strand hand-wound cable used a 90 mm transposition length; smaller transposition length L further reduces AC loss but forces gentler strand geometry (bending-radius constraint). The punched strand meander (each strand periodically moves edge-to-edge through the cross-section) is the cleanest existing physical realization of 'identical electromagnetic history'.

## 2. [HIGH|V|docs] Wikipedia: Braid group (Artin B_n, pure braid group P_n, B_n -> S_n)
URL: https://en.wikipedia.org/wiki/Braid_group
DESC: Full article read and verified. Gives exactly the machinery needed to formalize Q4's 'braid word / cross sequence': generators sigma_i with relations sigma_i sigma_{i+1} sigma_i = sigma_{i+1} sigma_i sigma_{i+1} and sigma_i sigma_j = sigma_j sigma_i for |i-j|>=2; forgetting over/under information gives a SURJECTIVE homomorphism B_n -> S_n with sigma_i |-> (i, i+1); its kernel is the pure braid group P_n (strands return to their own start slots); P_n is an iterated semidirect product of free groups (1 -> F_{n-1} -> P_n -> P_{n-1} -> 1); braid word problem is efficiently solvable with normal forms; GAP can compute in B_n.
NOTES: Direct recipe for the Q4 criterion: a cross sequence IS a braid word w in the sigma_i; the per-station cross-section state is the image of each prefix of w in S_n (slot assignment); the cable is periodic and perfectly transposed iff w closes in P_n after p periods (each strand returns to its own start) AND the cyclic group generated by the image of w in S_n acts transitively on positions so every strand visits every slot. Commutator-subgroup refinements (which pure braids realize a given permutation with minimal crossings) are in Orevkov 2017, afst.centre-mersenne.org.

## KEY INSIGHTS
- Classical criterion (transformer/machine practice): perfect (complete) transposition means every strand occupies every position in the cross-section for equal lengths, so all strands link equal leakage flux, induced EMFs are equal, circulating currents vanish, and 'all the subconductor currents remain the same' (Pyrhonen, Design of Rotating Electrical Machines, https://archive.org/stream/design-of-rotating-electrical-machines/Design%20of%20rotating%20electrical%20machines_djvu.txt). Standard litz loss models explicitly assume this (Nottingham thesis: 'all previous models have been developed under the condition of perfect transposition of the wires across the axial length', https://research.nottingham.edu.cn/files/633676087/Full_Thesis_Eraldo_ready_for_submission.pdf).
- Computable discrete criterion (proposed, ready for Q4): sample the cable at S stations and form the position matrix M in {1..N}^S x N (or over shell/azimuth cells). Perfect transposition <=> (a) each strand's row visits each position with equal multiplicity (Latin-square / Berger round-robin property: rotating N-1 slots around one fixed slot each step is the classic circle-method construction); (b) generalized exposure equality: sum_s Phi(M[s,k]) is identical for all strands k for a function basis Phi matched to the multipole expansion of the field (e.g. r, r^2, r*cos(theta), r*sin(theta) for a leakage field ~ perpendicular to the bundle); (c) pair discrepancy D = max_{i,j} |sum_s Phi(pos_i(s)) - sum_s Phi(pos_j(s))| / max_s Phi -> 0 is the quantitative 'distance from perfect transposition' to report as a scalar alongside Rac/Rdc.
- Braid-group formalization (verified on https://en.wikipedia.org/wiki/Braid_group): a cross sequence is exactly a braid word w in Artin generators sigma_i (relations sigma_i sigma_{i+1} sigma_i = sigma_{i+1} sigma_i sigma_{i+1}, sigma_i sigma_j = sigma_j sigma_i for |i-j|>=2). Slot assignment at each station = image of the word prefix under the surjection B_n -> S_n (sigma_i |-> (i, i+1)); kernel = pure braid group P_n. A periodic cable is perfectly transposed iff the period word w satisfies: w^p closes in P_n (strands return to their own slots - the 'event graph' is a union of closed carrier cycles) and the cyclic group <image(w)> <= S_n acts transitively (every strand reaches every slot). Tools: braidlab (Matlab, macOS binaries, GPL-3.0, https://github.com/jeanluct/braidlab) or cbraid (C++) for normal forms/word arithmetic.
- Roebel-cable evidence and design rules: full transposition along the length cuts AC losses by ~x2 versus the monolithic conductor (effective strand width ~ half the cable width); typical transposition pitch is 13-17 strand widths (punched or laser-cut meandering strands; e.g. 90 mm for a 5-strand cable); and smaller transposition length L further reduces AC loss (Goldacker review https://arxiv.org/abs/1406.4244; Wang 2022 https://www.sciencedirect.com/science/article/pii/S2772830722000187). This gives the Q3 sensitivity knob: Rac/Rdc improves with shorter period until bending strain/manufacturability limits.
- Twisting is NOT transposition: in a simply twisted/bunched bundle, strands rotate around the bundle axis at nearly constant radius, so inner strands remain inner and outer remain outer, leaving bundle-level skin effect; measured frequency-dependent losses 'differ extremely' with internal structure (Rosskopf/Baer/Joffe, https://www.researchgate.net/publication/262772004_Influence_of_Inner_Skin-_and_Proximity_Effects_on_Conduction_in_Litz_Wires). This is the physics justification for Q3's braid-over-twist comparison and for requiring RADIAL exchange (crossovers) in the Q4 topology, not just azimuthal rotation.
- CTC practice gives the industrial template for the criterion: a continuously transposed conductor rolls one enamelled rectangular strand over the top of the stack at each pitch so that after N steps every strand has occupied every stack position exactly once - an engineered Latin square - which suppresses eddy and circulating losses in transformer LV windings; the transposition pitch (set by the smallest winding diameter, strand count and size) is the single tunable parameter (manufacturer/industry pages on CTC at deangeliprodotti.com; CTC FEM models at sciencedirect.com, Geissler 2016). Residual imbalance converts to circulating current with amplitude falling as the inverse square of the connection length between parallel junctions (arXiv:2411.07235, https://arxiv.org/abs/2411.07235).

## 1. [HIGH|V|docs] Wikipedia: Skin effect (exact Bessel/Kelvin formulas)

## KEY INSIGHTS
- Exact Q1 validation formula set (verified on https://en.wikipedia.org/wiki/Skin_effect): J(r) = J(a) J0(kr)/J0(ka) with k = sqrt(-j*omega*mu*sigma) = (1-j)/delta; internal impedance per unit length Z_int = k J0(ka) / (2 pi a sigma J1(ka)); DC limits R = 1/(pi a^2 sigma) and L_int = mu/(8 pi) = 50 nH/m; high-frequency limit Rac/Rdc -> a/(2*delta); over 98% of current flows within 4 delta.
- Numerical reference target computed from these formulas (pure-Python J0/J1 power series, validated against J0(1)=0.76519769, J1(1)=0.44005059) for the exact competition case (2 mm dia copper, sigma=5.8e7, mu_r=1): delta = 0.1478 mm, a/delta = 6.767, Rdc = 5.488 mOhm/m, and Rac/Rdc = 1.966 (50 kHz), 2.662 (100 kHz), 3.647 (200 kHz), 5.609 (500 kHz), 7.822 (1 MHz); L_int(200 kHz) = 14.7 nH/m vs 50 nH/m DC. The FEM at 200 kHz should land near Rac/Rdc = 3.65 — that is the number the mesh must converge to. (Formula source: https://en.wikipedia.org/wiki/Skin_effect)
- Mesh convergence practice (verified: https://www.comsol.com/support/learning-center/article/understanding-the-options-for-meshing-and-geometric-modeling-of-conductors-in-electromagnetic-fields-81171): make element size <= skin depth in the surface layer; use a boundary-layer/inflation mesh with first layer ~ delta, growth 1.5-2.5, total depth ~ conductor size/10; at least 8 quadratic elements around the wire circumference; reserve impedance/surface BCs for delta ~100x smaller than the conductor — for this problem (a/delta = 6.8) mesh the volume with a refined skin, and run the convergence study as an elements-per-delta sweep at fixed frequency. Corroborating rules from search results: Altair/Iowa State 'at least 2 elements per skin depth'; ANSYS 'penetration ~4-5 skin depths'.
- No scipy needed for the Bessel evaluation: scipy.special.jv(0, k*a) and mpmath.besselj accept complex arguments directly (Kelvin ber/bei are just Re/Im of J0 at complex argument); a ~20-line power series in pure Python also works at these argument magnitudes (|ka| ~ 9.6). Sign convention matters: k = sqrt(-j*omega*mu*sigma) for e^{+j omega t}.
- macOS-native open-source solver path (verified): xfemm (https://github.com/crobarcro/xfemm) rebuilds FEMM 4.2 planar/axisymmetric magnetics incl. AC eddy problems with cmake-built headless fmesher/fsolver binaries and an Octave/MATLAB interface; fallback is official FEMM 4.2 + pyfemm under Wine (https://github.com/cenit/FEMM, Oct2023 build improved Wine compatibility), which supports open boundaries via Kelvin transformation / IABC (mi_makeABC) and per-circle max-element-size control for skin-layer refinement. Extract Rac from the harmonic solution as Rac = 2*P_loss/I^2 and plot J(r)/J(a) against J0(kr)/J0(ka) for the validation figure.
- Validation figure recipe that satisfies 'validate against theory': plot FEM |J(r)| vs the exact J0(kr)/J0(ka) curve, report delta from the J(r) e-folding, show Rac/Rdc converging to 3.647 as elements-per-delta increases (1, 2, 3, 4+ per delta), and show L_int trending from 50 nH/m (DC) toward 14.7 nH/m at 200 kHz (https://en.wikipedia.org/wiki/Skin_effect; https://www.comsol.com/support/learning-center/article/understanding-the-options-for-meshing-and-geometric-modeling-of-conductors-in-electromagnetic-fields-81171).
